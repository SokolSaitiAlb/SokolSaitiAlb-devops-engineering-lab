# Production-Style DevOps Engineering Lab

A small, reproducible DevOps portfolio project built around **Ops Notes API**: a dependency-free Python HTTP service with file-backed persistence. It demonstrates the path from local development through tests, CI, container packaging, basic security checks, deployment, health checks, backup/restore and incident recovery.

> **Scope:** learning and portfolio service, not a public multi-tenant production API. It has no authentication and its JSON store supports one service instance. Keep ports loopback-bound unless access control and TLS are deliberately added.

## Run locally on CachyOS

Python 3.12+ is sufficient; the runtime uses only the standard library.

    git clone https://github.com/SokolSaitiAlb/SokolSaitiAlb-devops-engineering-lab.git
    cd SokolSaitiAlb-devops-engineering-lab
    mkdir -p .local-data
    HOST=127.0.0.1 PORT=8080 DATA_FILE="$PWD/.local-data/notes.json" python app/src/service.py

In another terminal:

    curl -fsS http://127.0.0.1:8080/healthz
    curl -fsS http://127.0.0.1:8080/readyz
    curl -fsS http://127.0.0.1:8080/
    curl -fsS -X POST http://127.0.0.1:8080/api/notes -H 'Content-Type: application/json' -d '{"text":"first reproducible deployment"}'
    curl -fsS http://127.0.0.1:8080/api/notes

Stop the foreground process with Ctrl+C. Notes remain in .local-data/notes.json.

## Run tests and lint

    python -m compileall -q app/src app/tests
    PYTHONPATH=app/src python -m unittest discover -s app/tests -v
    python -m pip install -r app/requirements-dev.txt
    ruff check app/src app/tests

CI runs these tests and lint checks on pushes and pull requests; it also builds the container image. Security workflows run Trivy against filesystem/configuration and the built image. **Results are generated by GitHub Actions.** No scan result is claimed here until a workflow run has completed.

## Docker or Podman

Docker Compose:

    docker compose up --build -d
    docker compose ps
    curl -fsS http://127.0.0.1:8080/healthz
    docker compose logs --tail=100 api
    docker compose down

Podman on CachyOS:

    podman compose up --build -d
    podman compose ps
    curl -fsS http://127.0.0.1:8080/healthz
    podman compose logs --tail=100 api
    podman compose down

The default API binding is 127.0.0.1:8080. To add the optional Nginx reverse proxy, start Compose with the reverse-proxy profile and verify http://127.0.0.1:8081/healthz. The named notes-data volume is retained by a normal compose down; avoid down -v unless deleting lab data is intended.

The image runs as UID/GID 10001, drops Linux capabilities in Compose, has a read-only root filesystem and writes state only under /data. Nginx is loopback-only and does not add public TLS or authentication.

## Operational exercises

- Health/readiness check: monitoring/check-health.sh http://127.0.0.1:8080
- Local-file backup and checksum: DATA_FILE=.local-data/notes.json BACKUP_DIR=backups ./backup-restore/backup.sh
- Restore validation: DATA_FILE=.local-data/notes.json ./backup-restore/restore.sh backups/notes-TIMESTAMP.json
- Controlled outage/recovery drill: ./incident-response/simulate-outage.sh docker or ./incident-response/simulate-outage.sh podman. This deliberately stops the local api service; read the runbook first.

For named-volume backup/restore, systemd deployment and recovery steps, see docs/runbooks/. A successful script exit is not the same as verified recovery; record observed commands, output, timestamps and record integrity after a real drill.

## Limitations

- No authentication, authorization, rate limiting or TLS. Loopback binding is the safe default.
- JSON-file persistence is intended for one service instance, not concurrent replicas or high write volume.
- /healthz reports process liveness; /readyz checks basic data-file and parent-directory access.
- CI/security results must be read from actual workflow runs. Do not publish fabricated pass/fail numbers or unreviewed scan output.
- Terraform and Kubernetes are deferred until there is a concrete deployment target or scaling requirement.
